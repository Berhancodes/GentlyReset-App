# Rive sandbox (isolated experiment)

This folder is a standalone [Rive CLI](https://rive.app/docs/cli/overview.md) project. It is **not** wired into Gently Reset. Nothing here is imported by the Expo app.

Requires [Rive CLI 1.2.0](https://rive.app/docs/cli/getting-started.md) (`rive --version`).

## What is in the scene

A rounded peach character (`Companion` artboard):

- looping idle with subtle breathing and a small vertical bob
- two short blinks during the 4-second idle
- a one-shot wave state that plays after each idle cycle, then returns to idle

Motion is authored at 60fps with cubic ease-in-out keyframes. No scripts, shaders, or complex effects.

## Commands

From the repo root, with `rive` on your `PATH`:

```bash
# compile check (writes nothing)
rive rive-sandbox --verify

# write an unsigned .riv for local / tools-enabled runtimes
rive rive-sandbox --once

# live preview window (rebuilds on save)
rive rive-sandbox

# headless frame captures (useful in CI / Cloud Agents)
rive rive-sandbox --screenshot=rive-sandbox/preview/idle.png --advance=1s
```

On macOS, keep `rive rive-sandbox` running in one terminal and edit `scene.rml` in Cursor. Saves rebuild the preview.

## Files the CLI cares about

| File | Role |
| --- | --- |
| `rive.yaml` | project name and log paths |
| `scene.rml` | the scene in Rive Markup Language |
| `AGENTS.md` / `CLAUDE.md` | official agent instructions generated by `rive create` |
| `.gitignore` | ignores `build/` |

`rive rive-sandbox --once` writes `build/rive-sandbox.riv`. That file is local-only and unsigned. This scene has no scripts, so an unsigned `.riv` is enough for local runtime experiments. A signed production export is `rive login` then `rive rive-sandbox --publish`.
